# NurtureHer Frontend

Premium React 18 dashboard for the NurtureHer women’s health platform.

## Stack

- React 18
- TypeScript
- Vite
- TailwindCSS
- Radix UI
- React Hook Form
- Framer Motion
- React Query
- Lucide Icons
- Recharts
- React Router

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
